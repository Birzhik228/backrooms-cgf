# Third party credits and asset permissions

This document describes the submission assets prepared on 15 November 2026.
`assets/asset-license-manifest.json` records the exact active files and hashes.
Older imported assets have been excluded from this submission; their presence
in repository history or a private local backup is not permission to distribute them.

## Original project assets

**Threshold Sentinel** is an original procedural quadruped built from mathematical
primitives, with original textures, articulation and seven animation clips.
`tools/generate_sentinel.py` reproduces its geometry and animation. It does not
import or trace the former Aranea mesh or carpet textures. The legacy directory
`assets/models/aranea/` and BRARAN3 cache format are retained for runtime
compatibility. See the model README, manifest and LICENSE.txt for the scoped
CC0-1.0 dedication of these newly generated assets.

**Threshold ambient music and pickup chime** are original oscillator/noise
compositions generated by `tools/prepare_release_audio.py`. They do not use the
Temporex or Horror Skunx recordings, a copied melody, or a generated imitation
of either artist. The generated audio assets carry CC0-1.0 metadata in
`assets/audio/manifest.json` and the audio license notice.

Environment geometry and textures, UI glyph geometry, procedural ambience and
other code-generated effects are project work with disclosed Codex assistance.
Code generation, procedural asset authoring and student work are distinguished
in `docs/AI_USE.md`; these credits do not assert independent student authorship.

## Libraries and runtime components

- **GLFW** supplies window creation and input. Copyright Marcus Geelnard and
  Camilla Lowy; zlib/libpng-style license. Notice: `docs/licenses/GLFW.txt`.
  Source: https://www.glfw.org/
- **GLAD 0.1.36** supplies generated OpenGL 3.3 loading code, reused from the
  provided lab support infrastructure. Upstream notices:
  `docs/licenses/GLAD.txt`. Source: https://github.com/Dav1dde/glad/tree/v0.1.36
- **SDL 2.32.10** supplies queued audio output in the macOS build. Copyright
  Sam Lantinga and contributors; zlib license. Notice:
  `docs/licenses/SDL2-LICENSE.txt`. Source: https://www.libsdl.org/
  The Mac package links SDL2 and GLFW statically; macOS system frameworks remain
  supplied by the operating system. The Windows release keeps its native audio.
- **Khronos platform header**, copyright 2008-2018 The Khronos Group Inc. Its
  permission and warranty notice remains in `include/KHR/khrplatform.h`.
- **GCC runtime libraries** are statically linked in the Windows build. The
  package notice identifies GPL-3.0-or-later with GCC Runtime Library Exception
  3.1. Package, GPL and exception notices are retained in `docs/licenses/`.
  Source: https://gcc.gnu.org/
- **MinGW winpthreads**, copyright the mingw-w64 project and the other named
  authors. Installed toolchain notices: `docs/licenses/WINPTHREAD.txt`.

OpenGL is the graphics API; the game uses its own renderer and gameplay code.
Python and any offline audio converters are development tools, not runtime
requirements. The Backrooms setting is an inspiration, with no claimed
association with another game or creator.

## Assets excluded from this submission

The former supplied Aranea GLB and textures, Temporex recording, Horror Skunx
pickup excerpt and YouTube creature-call excerpts are excluded because original
redistribution authority was not established. Pixabay player/heavy footsteps
and the Partygoer excerpt have identified Pixabay licenses; they were replaced
with CC0 sources to simplify distribution of the complete source-and-assets
package. They are not described as universally unlicensed.

See `docs/asset-permissions-2026-11-15.md` for the decisions and primary links.
Local backups, Git history, old captures and earlier packaged builds are not part
of the submission archive. Screenshots and recordings used in the final report
or video should correspond to the updated submission assets.
