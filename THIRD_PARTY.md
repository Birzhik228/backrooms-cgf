# Third-party components

- **Background music:** the user's supplied `videoplayback.m4a`, requested for the soundtrack following “Numbers — Temporex.” The original is preserved and a compatible MP3 conversion is bundled under `assets/audio/music/`. This recording is separate from the CC0 footstep assets. See [music provenance](assets/audio/music/README.md) for the source hash and conversion details.

- **GLFW:** window creation and input. Linked from the installed MSYS2 MinGW package. Copyright Marcus Geelnard and Camilla Löwy. The installed zlib/libpng-style license is retained in `docs/licenses/GLFW.txt`. Project: https://www.glfw.org/.
- **GLAD 0.1.36 generated loader:** `common/glad.c` and `include/glad/glad.h`, reused from the user's `BR_A1` support files. Their generation header identifies OpenGL 3.3. This reuses loader infrastructure, not the assignment's scene logic. Upstream license notices are retained in `docs/licenses/GLAD.txt`. Source: https://github.com/Dav1dde/glad/blob/v0.1.36/LICENSE.
- **Khronos platform header:** `include/KHR/khrplatform.h`. Copyright 2008–2018 The Khronos Group Inc. Its permission and warranty notice remains in the header.
- **GCC runtime libraries:** the Windows build statically links the MinGW GCC runtime. The installed MSYS2 `gcc-libs` notice identifies libgcc and libstdc++ as GPL-3.0-or-later with the GCC Runtime Library Exception 3.1. Copies of the GPL, runtime exception and package notices are in `docs/licenses/`. GCC: https://gcc.gnu.org/.
- **MinGW winpthreads:** runtime support from the installed toolchain, copyright the mingw-w64 project and other named authors. The installed notices are retained in `docs/licenses/WINPTHREAD.txt`.
- **Recorded footsteps:** six real shoe footfalls by **GboxMikeFozzy**, released under **CC0 1.0 Universal** at [OpenGameArt](https://opengameart.org/content/footsteps-0). Original OGG files and processed mono WAV derivatives are retained in `assets/audio/footsteps/`; provenance and SHA-256 hashes are in that directory's `manifest.json`. See `docs/licenses/footsteps-CC0.txt`. The recordings were filtered and converted for softer indoor playback; they are not generated sound effects.

Version 0.7 removes the user-supplied photo assets, billboard renderer and pursuit code from the active project. Earlier versions are preserved in the local backups.

GLFW and GLAD are third-party work. OpenGL is a graphics API. The Backrooms theme is an inspiration, without a claim of affiliation with an existing game. Surface patterns and environment geometry are generated by project code. Version 0.8 uses the credited real footstep recordings; the fluorescent hum, clothing rustle and missing-recording fallback remain procedural. See `docs/AI_USE.md` for assistance attribution.
