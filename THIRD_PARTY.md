# Third-party components

- **Aranea Membri creature model and textures:** the user-supplied `rec-room-backrooms-entity-62-aranea-membri.zip` contains `source/Scene.glb` and two carpet PNGs. These original files are retained unchanged under `assets/models/aranea/`. The current game uses the supplied geometry and textures through offline-generated animation and RGB caches. The source has no rig or animation: the four leg chains, head/jaw articulation, walk/run/capture cycles and integration are project work with Codex assistance. No accompanying author or license document was supplied, so the original creator and redistribution terms are not established here; no CC0 or other license is asserted. The archive's title is not evidence of authorship or affiliation. See [model provenance and conversion notes](assets/models/aranea/README.md). Blender and Python/Pillow are offline conversion tools, not runtime dependencies.

- **Background music:** the user's supplied `videoplayback.m4a`, requested for the soundtrack following “Numbers — Temporex.” The original is preserved and a compatible MP3 conversion is bundled under `assets/audio/music/`. This recording is separate from the CC0 footstep assets. See [music provenance](assets/audio/music/README.md) for the source hash and conversion details.

- **GLFW:** window creation and input. Linked from the installed MSYS2 MinGW package. Copyright Marcus Geelnard and Camilla Löwy. The installed zlib/libpng-style license is retained in `docs/licenses/GLFW.txt`. Project: https://www.glfw.org/.
- **GLAD 0.1.36 generated loader:** `common/glad.c` and `include/glad/glad.h`, reused from the user's `BR_A1` support files. Their generation header identifies OpenGL 3.3. This reuses loader infrastructure, not the assignment's scene logic. Upstream license notices are retained in `docs/licenses/GLAD.txt`. Source: https://github.com/Dav1dde/glad/blob/v0.1.36/LICENSE.
- **Khronos platform header:** `include/KHR/khrplatform.h`. Copyright 2008–2018 The Khronos Group Inc. Its permission and warranty notice remains in the header.
- **GCC runtime libraries:** the Windows build statically links the MinGW GCC runtime. The installed MSYS2 `gcc-libs` notice identifies libgcc and libstdc++ as GPL-3.0-or-later with the GCC Runtime Library Exception 3.1. Copies of the GPL, runtime exception and package notices are in `docs/licenses/`. GCC: https://gcc.gnu.org/.
- **MinGW winpthreads:** runtime support from the installed toolchain, copyright the mingw-w64 project and other named authors. The installed notices are retained in `docs/licenses/WINPTHREAD.txt`.
- **Recorded footsteps:** six real shoe footfalls by **GboxMikeFozzy**, released under **CC0 1.0 Universal** at [OpenGameArt](https://opengameart.org/content/footsteps-0). Original OGG files and processed mono WAV derivatives are retained in `assets/audio/footsteps/`; provenance and SHA-256 hashes are in that directory's `manifest.json`. See `docs/licenses/footsteps-CC0.txt`. The recordings were filtered and converted for softer indoor playback; they are not generated sound effects.

For v0.11, the user supplied a screenshot as the visual reference for a creature they associated with **MONOCHROME/Room on Roblox**. That version's Watcher was custom project geometry inspired by the reference; no Roblox mesh, animation or texture was extracted for it. The first v0.12 creature used the separately supplied `smiler-backrooms.zip` and its rigged `source/Zombie Scream.fbx`; that model and the original scream animation are now historical and recoverable from local backups. The current replacement is the separate Aranea GLB described above. Neither the Watcher nor Smiler is the source of the Aranea mesh. Codex assistance is disclosed in `docs/AI_USE.md`.

Version 0.7 removed the earlier user-supplied photo assets, billboard renderer and photo-pursuit implementation. Those remain absent from the current version; the new creature uses volumetric geometry and new behavior. Earlier project versions are preserved in local backups.

GLFW and GLAD are third-party work. OpenGL is a graphics API. The Backrooms theme is an inspiration, without a claim of affiliation with an existing game. Surface patterns and environment geometry are generated by project code. The current Aranea mesh and carpet textures are supplied assets; all its rig mapping, locomotion, head/jaw and capture animation and runtime integration are project work. Player footsteps and current Aranea cues use the credited recordings/reference excerpts; fluorescent hum, clothing rustle, ambient effects, the low capture impact and missing-recording fallback are procedural. The capture roar remains supplied audio. See `docs/AI_USE.md` for assistance attribution.

- **Jumpscare roar:** user-supplied `347410__zerokingfull__monster-roar-02.ogg`; original and derived WAV in `assets/audio/jumpscare/`. See [provenance](assets/audio/jumpscare/README.md). License metadata was not supplied or verified.

- **Current player footsteps:** user-supplied `freesound_community-indoor-footsteps-6385.mp3`, extracted to six universal contacts. Original and manifest: `assets/audio/footsteps-player/`.
- **Previous creature footsteps and fallback:** user-supplied `universfield-heavy-walking-footsteps-352771.mp3`, extracted to four heavy contacts. Original and manifest: `assets/audio/footsteps-monster/`. License metadata for these two supplied files was not provided or verified. This bank is no longer used for current Aranea soil contacts. See [conversion notes](docs/key-and-hiding.md).
- **Aranea soil contacts:** four Sand recordings by **Fantozzi**, released as **CC0 1.0 Universal** at [OpenGameArt](https://opengameart.org/content/fantozzis-footsteps-grasssand-stone). Original FLACs and decoded WAVs are retained in [source/soil](assets/audio/aranea/source/soil/README.md). No Stone recordings are used. Walk/run variations are filtered and pitch-adjusted derivatives.
- **Aranea calls:** adapted from the user's selected [Aranea Membri Sounds (Backrooms Entity)](https://www.youtube.com/watch?v=wzUCsTD23rg), uploaded by Slappy The Dummy and crediting @frag2, blended with the supplied ZeroKingFull scream described above. The retained roar excerpt, source hashes and processing are documented in [assets/audio/aranea](assets/audio/aranea/README.md). The video metadata does not state a reuse license. The historical running excerpt is retained but no longer used. These are edited recordings, not original performances. Player footsteps and capture audio retain their previous sources.
