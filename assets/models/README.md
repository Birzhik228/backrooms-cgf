# Runtime creature model

The current creature is the user-supplied [Aranea Membri](aranea/README.md). Its original GLB and two PNGs, converted animation/texture caches, provenance notes and rebuild instructions are in `aranea/`. The project adds four articulated leg chains, head/jaw movement and seven animation clips; the source contained no rig or animation.

The previous Smiler FBX and cache are historical and recoverable from the local backup made before this replacement. The older procedural silhouette OBJ remains recoverable in the v0.11 project backup. Neither is loaded by this version.

Keep `aranea/aranea.brm`, `aranea/creature-color.rgb` and `aranea/creature-normal.rgb` with the matching rebuilt executable. The original source assets are retained for provenance and offline rebaking; neither Blender nor Python is needed to run the game.
