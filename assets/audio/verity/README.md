# Pickup chime

Original two-second three-tone synthesized chime, created in
`tools/prepare_release_audio.py` with disclosed Codex assistance. There is no
voice, lyric or excerpt from an existing song. The chime plays once on pickup,
with short edge fades, existing master volume and mute behavior.

The newly synthesized audio is dedicated to CC0 1.0 Universal:
https://creativecommons.org/publicdomain/zero/1.0/
`manifest.json` records its generator, hash, format, duration and levels.
