# Player footsteps

Six processed shoe contacts by GboxMikeFozzy, licensed CC0 1.0 Universal.
Source: https://opengameart.org/content/footsteps-0
License: https://creativecommons.org/publicdomain/zero/1.0/

The six runtime WAVs derive from `../footsteps/step-01.wav` through `step-06.wav`.
Gentle tanh transient compression and normalization to 0.88 peak retain the real
shoe contacts while maintaining the existing Partygoer audibility without sharp
clipped peaks. Original OGGs, conversion details and original/output hashes
remain in `../footsteps/`. `manifest.json` records processing and input/output
hashes. Rebuild with `python tools/prepare_release_audio.py`.
